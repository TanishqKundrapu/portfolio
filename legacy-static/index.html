About Me

Curiosity-driven engineer, builder at heart

I'm a Computer Science Engineering undergraduate at GITAM University, driven by curiosity about algorithms, machine learning, and AI-driven systems for real-world problems. What started as curiosity about how things work has grown into a disciplined pursuit of writing clean, scalable code and designing systems that matter.

I build full-stack products and deep learning systems through independent work and hackathons, sharpen my edge through competitive programming on LeetCode and HackerRank, and I'm now diving into Cloud & DevOps — learning to ship software that doesn't just work on my machine, but scales reliably in production.

I've taken on leadership roles at Meta Developer Communities — starting as Competitive Programming Domain Lead and now serving as Secretary — and won hackathons like TechSprint (GDGoC State-Level). Above all, I'm a relentless, continuous learner — always one step into the next technology, the next algorithm, the next challenge.
